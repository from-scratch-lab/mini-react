# ADR 0002: 조건부 항목(9단계)은 구현하지 않는다

- 상태: 채택 (2026-11-09)
- 맥락: ADR 0001의 9단계는 "측정으로 이득이 확인될 때만" 하는 항목이다: VNode 클래스(`#dom` 비공개 필드), `collectNodes` 제거, 순수 자식 `memo`, 실제 DOM과 가상 트리 어긋남(drift) 감지.

## 측정

Node 22 + jsdom, 1,000행, 같은 데이터 다시 렌더, 31회 중앙값 (`dev` 683b994):

| 항목 | 값 |
|---|---:|
| diff 전체 | 8.0ms |
| 그중 `collectNodes`(이전 트리 전체를 Set에 담기) | 1.0ms (약 13%) |
| 같은 시나리오 Chrome 152 diff | 4.2ms, patch 0.5ms, layout 0ms (`docs/benchmarks.md`) |

## 결정

| 항목 | 결정 | 이유 |
|---|---|---|
| `collectNodes` 제거 (`vnode.dom != null`로 판단) | 하지 않음 | 이득이 최대 1ms(13%)인데, "이전 트리의 모든 노드가 실제 DOM을 가진다"는 불변식에 기대게 된다. 실패 복구·attach·vnode 재사용 경로에서 이 불변식이 깨지면 엉뚱한 노드를 공유한다. 이득보다 위험이 크다 |
| VNode 클래스 + `#dom` | 하지 않음 | 지금 `dom`은 열거되지 않는 속성이라 직렬화·비교에서 이미 숨는다. 클래스로 바꾸면 테스트의 객체 비교·`cloneVNode` 경로를 모두 바꿔야 하고, 잰 성능 이득이 없다 |
| 순수 자식 `memo` | 하지 않음 | 자식 컴포넌트는 인스턴스 없이 그 자리에서 펼쳐지는 순수 함수다. 건너뛸 단위가 없고, 같은 데이터 다시 렌더가 이미 패치 0·DOM 변경 0·Chrome diff 4ms다. 같은 vnode 객체 재사용 건너뛰기는 이미 있다 |
| drift 감지 | 하지 않음 | 차등 fuzz의 refs 검사(가상↔실제 노드가 하나씩 맞물림)가 테스트에서 같은 일을 한다. 런타임 검사는 매 patch 비용이 든다 |

## 결과

- 엔진 코드는 ADR 0001의 1~8단계 상태로 마무리한다.
- 다시 열 조건: 10,000행 이상에서 diff가 프레임 예산(16ms)을 넘는 실제 화면이 생기면 `collectNodes` 제거부터 측정한다.
