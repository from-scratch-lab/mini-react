Phase 1 · Virtual DOM + Diff + Patch

오른쪽 테스트 영역의 HTML을 고치고 Patch를 누르면, 이전 가상 트리와 비교해 바뀐 부분만 왼쪽 실제 영역에 반영합니다. 바뀐 노드는 잠깐 노랗게 표시됩니다.

실제 영역

미니 리액트 체크리스트

테스트 영역에서 이 카드를 고쳐 보세요. 텍스트, 속성, 목록 순서 모두 바꿀 수 있습니다.

  • Virtual DOM 만들기
  • Diff 알고리즘
  • Patch로 실제 DOM 반영
이렇게 바꿔 보세요
  • 텍스트 수정 → TEXT
  • class·속성 수정 → PROPS
  • <li> 추가·삭제 → CREATE / REMOVE
  • <p>를 <blockquote>로 → REPLACE
  • key 있는 <li> 순서 바꾸기 → MOVE

참고: 줄바꿈이 섞인 공백만 있는 텍스트는 들여쓰기로 보고 버립니다(JSX와 같은 규칙). 인라인 요소 사이에 띄어쓰기가 필요하면 같은 줄에 공백을 쓰세요. <script>·<style>·on* 속성 등은 실제 영역에 넣지 않습니다.
