브라우저 벤치마크

npm run bench(Node + jsdom)와 같은 시나리오를 이 브라우저에서 돌립니다. 행 하나는 <tr key><td>id</td><td><a>label</a></td><td><a>x</a></td></tr>입니다.

읽는 법

  • 패치 · DOM 변경 기록 · 붙임+뗌 · 새 노드는 매번 같은 값이 나오는 지표입니다. jsdom 결과(docs/benchmarks.md)와 같아야 하며, CI 성능 예산이 이 값을 지킵니다.
  • diff · patch · layout ms는 이 브라우저의 시간입니다. layout은 patch 뒤 레이아웃을 강제로 계산한 시간이라 Reflow 비용이 들어갑니다. 기계·브라우저마다 다르니 같은 기계에서 비교하세요.
  • 이동: 엔진이 실제로 만든 MOVE 수 / LIS로 구한 이론 최소 / 같은 key 순서를 React식(lastPlacedIndex)으로 처리했을 때의 수. React 열은 알고리즘을 따라 센 값이며 실제 React를 돌린 결과가 아닙니다.
