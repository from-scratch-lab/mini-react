# Mini React Project

## Goal
- Implement a working Mini React using Vanilla JavaScript or TypeScript.
- Follow the assignment requirements in README.md.

## Constraints
- Do not use React, Vue, or other UI frameworks.
- Reuse the Phase 1 Virtual DOM, Diff, and Patch in Phase 2.
- Hooks and state are allowed only in the root component.
- Child components must be stateless and receive props.
- Patch only changed DOM nodes; preserve unchanged nodes.

## Workflow
- Inspect relevant existing code before making changes.
- Keep changes scoped to the requested feature.
- Follow existing project conventions.
- Add or update unit tests for implemented behavior.
- Include meaningful edge cases in tests.

## Verification
- Run relevant tests after functional changes.
- Verify browser interactions when UI behavior changes, if possible.
- Never report tests as passed unless actually executed.
- Report changed files, test results, and remaining issues.
